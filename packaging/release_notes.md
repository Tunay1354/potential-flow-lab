**Flowy — 2D potential flow** (Aerodynamics, İzmir Institute of Technology, Fall 2026)

### Run it (Windows 10 / 11, no Python needed)
1. Download **Flowy-…-windows.zip** below (under *Assets*).
2. Right-click it → **Extract All…** → Extract. (Do not run it from inside the zip.)
3. Open the extracted **Flowy** folder and double-click **Flowy.exe**.
4. If Windows says *"Windows protected your PC"*: click **More info → Run anyway** (the exe is not signed).

The first start takes 15–30 s (the fast kernels are compiled once; the loading screen says so); later starts
take a few seconds. Settings and logs are kept per user (Help → Open log folder).
