**Flowy — 2D potential flow** (Aerodynamics, İzmir Institute of Technology, Fall 2026). Windows 10 / 11, no
Python needed. Two ways, the same program — download one of them below (under *Assets*):

### A — Installer: **Flowy-…-setup.exe**
1. Double-click it. If Windows says *"Windows protected your PC"*: **More info → Run anyway** (not signed).
2. Choose the language, *only for me* (no administrator needed) or *all users*, the folder, the Start menu
   folder, a desktop shortcut, opening `.pflow` files with Flowy, starting with Windows.
3. **Install**, then **Finish** (with *Launch Flowy* ticked).

Uninstall: Settings → Apps → Installed apps → Flowy → Uninstall (or Start menu → Flowy → Uninstall). It asks
whether to delete your settings and data too; scene files (`.pflow`) you saved are never deleted. Installing a
newer version over it keeps the folder and your settings.

### B — Portable: **Flowy-…-windows.zip**
1. Right-click it → **Extract All…** → Extract. (Do not run it from inside the zip.)
2. Open the extracted **Flowy** folder and double-click **Flowy.exe** (SmartScreen: **More info → Run anyway**).

The first start takes 15–30 s (the fast kernels are compiled once; the loading screen says so); later starts
take a few seconds. Settings and logs are kept per user (Help → Open log folder).
