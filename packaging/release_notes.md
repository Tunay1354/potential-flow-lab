**Flowy — 2D potential flow** (ME 470 Introduction to Aerodynamics, Semester Project 1, İzmir Institute of
Technology, Fall 2026). Windows 10 / 11, no Python needed. Two zips below (under *Assets*), the same contents
except the program — each one is the complete submission:

| | `3_Program\` holds |
|---|---|
| **Flowy-…-portable.zip** | the program folder, ready to run (no installation) |
| **Flowy-…-setup.zip** | the installer (Start menu, desktop shortcut, `.pflow` files open with Flowy, uninstaller) |

Inside: `1_Report.pdf`, `2_User_Guide.pdf`, `3_Program\`, `4_Source_Code\`, `5_Verification\` (the program's
own verification report) and `README.txt`.

1. Right-click the zip → **Extract All…** → Extract (the program does not run from inside a zip).
2. *Portable*: open `3_Program\Flowy` and double-click **Flowy.exe**. *Setup*: double-click
   `3_Program\Flowy-…-setup.exe`, choose the language, for whom, the folder and the options → Install → Finish.
3. If Windows says *"Windows protected your PC"*: **More info → Run anyway** (the program is not signed).

The first start takes 15–30 s (the fast kernels are compiled once; the loading screen says so); later starts
take a few seconds. Settings and logs are kept per user (Help → Open log folder). Uninstalling the installed
program (Settings → Apps → Installed apps → Flowy) asks whether to delete your settings and data too; scene
files (`.pflow`) you saved are never deleted.
